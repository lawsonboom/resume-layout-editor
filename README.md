# 简历排版工作台

一个在浏览器中运行的模块化简历编辑器。它负责 PDF/TXT 导入、头像插入、版式与双色重点色选择、模块逐项编辑、A4 预览和导出 PDF/JPG；任意 AI 都可以通过复制提示词、粘贴 JSON 回答参与内容筛选，所有建议都先对比、再由你逐项确认。

工作台默认使用空白模板，不包含姓名、联系方式、经历、成果、头像或作品图片。上传和填写的内容只保存在当前浏览器的本地存储中，不会由此静态网站上传到服务器。

## 打开

线上版本：[打开简历排版工作台](https://lawsonboom.github.io/resume-layout-editor/)。

本地使用时双击 `start.command`；终端窗口需要在使用期间保持开启。

也可以在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 使用流程

1. 上传文字型 PDF/TXT，或直接粘贴简历原文。
2. 粘贴招聘需求；中间的“面试准备”会先在本地生成关注点、问题、参考答法、回答建议和行业注意。
3. 复制提示词给你常用的 AI，把其 JSON 回答粘回，查看每一项修改前后的对比。
4. 勾选要采用的建议再应用。姓名、联系方式、原文没有的数字及删除操作会默认取消选择。
5. 在右侧选择“专业标准 / 创意侧栏 / 紧凑一页”，再选择一组双色重点色。
6. 点击头像区或“选择头像”，插入 JPG、PNG、WebP 图片；每个模块都能逐项编辑。
7. “关键成果”优先单行，超过 4 项自动排成两行；每项可选择简洁图案。
8. 中间预览支持带阻尼的双指缩放和双指拖动；桌面端可拖动两条分隔线调整三栏宽度。头像大小可在 64–136px 间连续调整。
9. 点击“导出”，选择 PDF 或高清 JPG。PDF 会直接下载，不再依赖浏览器打印窗口。工作台始终按一页 A4 输出；内容过多时先自动压缩，达到可读下限后会提示精简，超出部分不会导出。

“参考答法”会在下划线上填写通用参考词，帮助理解回答结构；使用时仍应换成自己的真实信息。标有“虚构示例”的内容不能直接当作个人经历使用。

应用 AI 建议后，中央 A4 会出现随机像素覆盖过渡，并重新适配为一页 A4。系统启用“减少动态效果”时会跳过动画。

## 边界

- 扫描图片 PDF 不含可提取文字，需要先 OCR，或直接粘贴文字。
- 没有调用任何 AI API，也不会替用户自动发送内容。
- AI 对比中的“安全项”和导出体检都是本地规则判断，属于提醒，不是事实核验或招聘通过保证。
- 草稿保存在当前浏览器的本地存储；清除浏览器站点数据会删除草稿。
- 头像和作品图会先在浏览器内压缩；图片过多仍可能超过本地存储容量。
- HEIC 暂不支持，可先在 macOS“预览”中导出为 JPG。
